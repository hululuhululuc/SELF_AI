# Security Policy

## Supported Versions

Security fixes are applied on the `main` branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Instead, report privately to the maintainers with:

- Vulnerability type and impact
- Affected files/modules
- Reproduction steps or proof of concept
- Suggested fix (if available)

If contact information is not yet listed in this repository, open a minimal issue requesting a private contact channel, without disclosing details.

## Response Targets

- Initial acknowledgment: within 72 hours
- Triage and severity assessment: within 7 days
- Fix timeline: depends on severity and complexity

## Scope

Typical in-scope concerns:

- Remote code execution paths
- Permission bypass
- Secret leakage
- Arbitrary filesystem access outside intended boundaries
- Unsafe tool execution bypassing guards
